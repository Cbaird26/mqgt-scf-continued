
This directroy contains the measurement data and the python code required to 
extract the macroscopicity value for the Vienna Na-cluster interference measurements 
from April 2025.

Macroscopicity_April2025.py: 
Python script to calculate the macroscopicity by Bayesian updating

talbotlau.py: 
Python module providing functions required for calculating Talbot-Lau 
interference patterns, visibilities, etc.

PowerScans_April2025.py:
Python script to analyze the power scans, extract visibilities, and compare with theory

Na-Cluster/Data_April2025/*:
Measurement data and mass spectra
