# Higgs portal review: public working draft

This directory contains unreviewed exploratory papers, audit notes and local consistency checks for Christopher Michael Baird's hypothetical MQGT-SCF two-singlet companion-sector EFT. ChatGPT (ZoraASI) provided AI assistance with mathematical derivation, analysis, programming and drafting. These are not independently peer-reviewed results or evidence that ethics or consciousness are measurable scalar fields.

The public draft pull request deliberately leaves `main`, the frozen independent-verification snapshot and the archived source corpus unchanged. References and model assumptions require independent expert verification before a journal submission or scientific release.

## Working-paper and source-audit orientation

`COMPREHENSIVE_WORKING_PAPER_2026-09-21.md` and `DUAL_SINGLET_HIGGS_PORTAL_DRAFT.md` are two related but separately scoped drafts. `CLAIMS_AND_RELEASE_GATE.md` is the authoritative running record of claim limits and remaining gates. Notes 14–17 cover model-conditional tree-level and spectral derivations, lepton-width floor, heavy-quark threshold pitfalls and source matching. Notes 18–20 identify and audit a candidate partial pion/kaon form-factor source and distinguish the toy 0–2 GeV kinematic integration weight from physical hadronic branching fractions.

**Research Note 21:** `RESEARCH_NOTE_21_SPECTRAL_SENSITIVITY_AND_OFFLINE_DATA_GATE.md` derives the exact weighted-mean spectral-ratio identity explaining why 0.414% of a toy kinematic kernel does not bound a QCD width fraction. `safe_omnes_manifest.py` is an original, offline, standard-library-only checker for four *pinned* upstream Omnès files (size + Git blob SHA-1; output raw SHA-256 and escaped byte samples after successful verification). `test_research_note_21.py` includes 15 passing local **synthetic-fixture and algebra** tests. Original upstream numerical input files have not been acquired or parsed, and no hadronic width is claimed. Once obtained, run `python3 safe_omnes_manifest.py /absolute/path/to/hipsofcobra/input`; any missing or mismatched input causes failure.

Open gates include source-pinned portal normalization; global vacuum and radiative stability; authenticated upstream Omnès bytes and safe grammar-specific parsing; validated, normalized, nonoverlapping hadronic spectra through the physically needed mass range; independent total-width/uncertainty analysis; collider acceptance and likelihood; H2 microscopic model-observable matching; bibliography, licensing, AI disclosure and external review. The conditional toy-model `c*tau_2 <= ~17.06 cm` leptonic-only limit is unchanged. Do not merge, mint DOI, or present these results as experimental verification merely because code tests pass.
