# Two-singlet EFT and experimental interfaces — public technical review

**Status:** Author-approved public *draft* on a review branch; NOT peer reviewed, not journal-submitted, not a GitHub release, not a DOI mint, and not an experimental finding. The PR is unmerged; frozen independent-verification release and original corpus are unchanged.

This package develops a restricted symmetric-vacuum, two-real-singlet effective theory motivated by the MQGT-SCF source archive, plus conditional open-system and H2 interfaces. It does not verify MQGT-SCF as a Theory of Everything or establish any consciousness/ethical scalar interpretation.

- `COMPREHENSIVE_WORKING_PAPER_2026-09-21.md`: broad dated synthesis of exploratory Research Notes 01–13; derived and illustrative results distinguished from unresolved links.
- `DUAL_SINGLET_HIGGS_PORTAL_DRAFT.md`: narrower dated collider working paper.
- `CLAIMS_AND_RELEASE_GATE.md`: evidence/assumption ledger and release requirements; read with later addenda, not as an automatically updated manuscript.
- `RESEARCH_NOTE_14_DECAY_AUDIT.md` through `RESEARCH_NOTE_17_THRESHOLD_AND_SPECTRAL_CERTIFICATION.md`: toy-model lepton and spectral checks, missing-channel inventory and hadronic-threshold caveats.
- `RESEARCH_NOTE_18_PARTIAL_SPECTRAL_MATCHING.md` through `RESEARCH_NOTE_21_SPECTRAL_SENSITIVITY_AND_OFFLINE_DATA_GATE.md`: paper-to-code matching for candidate low-energy pion/kaon amplitudes, upstream input provenance gate and a synthetic spectral-sensitivity calculation. No actual source Omnès inputs were obtained or parsed.
- `RESEARCH_NOTE_22_COMPRESSED_SPECTRAL_WINDOW_BENCHMARK.md`: *distinct* illustrative `m1=10,m2=11.5 GeV` point whose virtual-mass endpoint is 1.5 GeV, conditionally removing the earlier 2–15 GeV pion/kaon extrapolation. Its leptonic-only `c*tau <= ~645 km` is not a predicted lifetime.
- `RESEARCH_NOTE_23_COMPRESSED_SPECTRUM_ROBUSTNESS.md`: exact 2×2 mass/portal rotation, asymmetric bare-mass perturbation interval for a *provisional* `Delta<=2 GeV` endpoint, and algebraic additional-width ratios required for selected proper decay lengths. `spectrum_robustness.py` reproduces the conditional formulae. This is not a radiative calculation or detector constraint.

Older test scripts cover the corresponding earlier toy algebra and synthetic fixtures. No external QCD code or numerical data were run or redistributed. The pinned four Omnès inputs remain unavailable; until authenticated and safely parsed, no pion/kaon width, total lifetime or full detector classification is established.
