# Two-singlet Higgs-portal paper — public review package

**Status:** Author-approved public *draft* on a review branch; NOT peer reviewed, not a journal submission, not a GitHub release, and not a new experimental finding.

This package develops a deliberately restricted, stationary, symmetric-vacuum two-real-singlet effective theory motivated by the MQGT-SCF research corpus. It is not a verification of MQGT-SCF as a Theory of Everything, nor a test of consciousness or ethical-field interpretations.

- `DUAL_SINGLET_HIGGS_PORTAL_DRAFT.md`: scientific manuscript draft, including the portal-normalization correction, diagonalization, three Higgs pair-production channels, and a dated experimental comparison.
- `CLAIMS_AND_RELEASE_GATE.md`: evidence/assumption ledger and outstanding preprint/journal submission gates.
- `higgs_portal_checks.py`: standard-library reproducibility checks for illustrative numerical comparisons and the orthogonal trace identity; these tests do not validate experimental physics or the complete theory.

**Provenance:** Draft assembled 2026-09-21 using the source corpus and continued-development repository. The frozen independent-verification release and original manuscripts remain unchanged. Source pages/equations and final literature checks must be pinned before a released preprint.
